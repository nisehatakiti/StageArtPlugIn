# Members Specification

StageArtPlugInのメンバーは、劇団サイトを構成する独立したコンテンツ種別として扱う。

## 1. コンテンツ構造

```text
メンバー
├─ メンバー一覧
├─ ○○
├─ ××
└─ △△
```

「メンバー」はコンテンツ種別であり、以下のコンテンツを持つ。

- メンバー一覧
- 個々のメンバーコンテンツ

### メンバー一覧

「メンバー一覧」はシステムが標準で提供する一覧コンテンツ。

公開されているメンバー個人コンテンツを、設定された表示順に従って一覧表示する。

### 個人コンテンツ

メンバーを1人追加するごとに、そのメンバーの個人コンテンツが1件作成される。

個人コンテンツは独立した公開ページを持ち、トップページやメニューなど、サイト内の任意の場所から直接配置・参照できる。

「看板役者」などの用途別コンテンツを別途作成する必要はない。

例えば山田太郎をトップページに掲載したい場合は、山田太郎のメンバー個人コンテンツを直接配置する。

## 2. メンバー標準項目

| 項目 | 必須 | 入力方式 | 備考 |
|---|---:|---|---|
| 名前 | ○ | テキスト | メンバー名 |
| Slug | ○ | 自動生成・編集可能 | 個人ページ識別子 |
| 写真 | ― | メディア | 個人ページ等で表示 |
| 役割 | ― | チェックボックス | 複数選択可能 |
| プロフィール | ― | リッチテキスト | 個人プロフィール |
| SNS | ― | URL | X、Instagram等 |
| 劇団共通自由記述項目 | ― | 共通項目への入力 | 劇団全体で定義 |
| 表示順 | ― | 並び替え | メンバー一覧の表示順 |
| 情報解禁 | ― | チェックボックス＋日時 | 未設定は公開状態になった時点から公開 |

## 3. 役割

役割はStageArtPlugInが標準で提供するプリセットから選択する。

1人のメンバーが複数の役割を選択できる。

```text
□ 俳優
□ 演出
□ 脚本
□ 制作
□ 音響
□ 照明
□ 舞台監督
□ 劇団代表
```

役割は自由入力ではなく、標準プリセットを使用する。

## 4. 劇団共通の自由記述項目

自由記述項目は、劇団全体で共通する項目定義として管理する。

```text
メンバー項目
├─ 趣味
├─ 好きな劇作家
├─ 特技
└─ ひとこと
```

項目定義と各メンバーの入力値は分離して管理する。

### 項目定義

各項目は少なくとも以下を持つ。

- 内部ID
- 項目名
- 説明・ヘルプテキスト
- 有効／無効状態
- 表示順

### 追加

新しい共通項目を追加すると、すべてのメンバーがその項目を利用できる。

既存メンバーの入力値は空欄で開始する。項目は任意入力とする。

### 編集

項目名や説明を編集できる。

項目を編集しても内部IDは変更せず、既存メンバーの入力値を維持する。

### 並び替え

共通項目の表示順を変更できる。

変更された表示順は、すべてのメンバーの編集画面および公開ページに共通して適用する。

### 無効化

使用しなくなった項目は削除せず、無効化する。

無効化すると、

- メンバー編集画面から非表示
- 公開メンバーページから非表示
- 新たな入力対象から除外

となる。

ただし、既存のメンバー入力値は削除せず保持する。

無効化時には以下の確認メッセージを表示する。

> 「{項目名}」を無効化しますか？
> この項目はメンバーの編集画面および公開ページに表示されなくなります。
> 入力済みのデータは削除されず、保持されます。
> 無効化後は、いつでも再利用できます。

無効化しても、項目の過去の表示順は保持する。

### 再利用

無効化した項目は再利用できる。

再利用すると、

- メンバー編集画面に再表示
- 公開メンバーページに再表示
- 以前のメンバー入力値をそのまま復元

する。

再利用時には以下の確認メッセージを表示する。

> 「{項目名}」を再利用しますか？
> 再利用すると、この項目がすべてのメンバーの編集画面および公開ページに再び表示されます。
> 以前入力されていたメンバーのデータもそのまま利用できます。

再利用時は、無効化前の表示順を復元する。再利用後は通常の並び替えで変更できる。

### 完全削除

初期実装では、メンバー共通自由記述項目の通常の完全削除機能は提供しない。

無効化を標準的な使用停止操作とする。

## 5. メンバーの表示順

個々のメンバーには表示順を持たせる。

管理画面ではドラッグ＆ドロップ等によってメンバーを並び替えられる。

```text
☰ 山田太郎
☰ 佐藤花子
☰ 鈴木一郎
☰ 田中美香
```

この表示順はメンバー一覧で使用する。

表示順は個人ページのURLやSlugとは独立して管理する。

## 6. 公開状態と情報解禁

メンバー個人コンテンツは公開状態と情報解禁日時を持つ。

公開状態が公開で、かつ情報解禁日時を設定していない場合は公開状態になった時点から公開する。

情報解禁日時を設定した場合、設定日時まではメンバー一覧および公開側のメンバーコンテンツとして利用しない。

管理画面では「情報解禁日を設定する」チェックボックスで設定の有無を制御する。チェックを外して保存すると保存済み日時を解除し、即時公開扱いに戻す。

情報解禁日時は日本時間で入力し、DBにはUTCで保存する。公開判定はアクセス時に行い、cron等で状態を切り替えない。

非公開・下書きのメンバーは公開ページに表示しない。

コンテンツ自体は残し、必要に応じて再公開できる。

## 7. メンバー個人コンテンツの配置

メンバー個人コンテンツは、他のサイトコンテンツと同様にサイト内の任意の場所から参照できる。

例えば、

```text
トップページ
├─ 次回公演
├─ 劇団代表挨拶
├─ 山田太郎
└─ お知らせ
```

のように、特定のメンバー個人コンテンツを直接トップページへ配置できる。

メンバー個人コンテンツを複数の場所から参照する場合も、同一のメンバーコンテンツを参照し、内容を複製しない。

## 8. 劇団代表挨拶との関係

「劇団代表挨拶」はメンバー個人コンテンツとは別の独立コンテンツとして扱う。

劇団代表挨拶では対象となるメンバーを選択する。

```text
劇団代表挨拶
├─ 対象メンバー → 山田太郎
├─ 写真 → 山田太郎から自動取得
├─ 名前 → 山田太郎から自動取得
├─ メンバーページへのリンク → 自動生成
└─ 挨拶本文 → 劇団代表挨拶側で入力
```

写真、名前、メンバーページへのリンクはメンバーコンテンツを参照して自動表示する。

劇団代表挨拶側では写真や名前を複製して管理しない。

そのため、メンバー側で写真や名前を変更した場合、劇団代表挨拶にも自動的に反映される。

## 9. 基本原則

メンバーに関するデータと、そのデータをどこに表示するかは分離する。

```text
Member
  ↓
人物情報の正本
  │
  ├─ メンバー一覧
  ├─ メンバー個人ページ
  ├─ トップページへの直接配置
  ├─ メニューからの参照
  └─ 劇団代表挨拶からの参照
```

メンバー情報を複製して別コンテンツとして管理するのではなく、1つのメンバーコンテンツを複数の場所から参照する。
