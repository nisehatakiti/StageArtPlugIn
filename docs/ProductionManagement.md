# 公演管理仕様

## Production

- WordPress custom post type `stageart_production` を使用する。
- 公開URLは `/production/{slug}/`。
- 公演名は必須、Slugは編集可能。
- 公演ページ自体の公開状態と各情報ブロックの情報解禁日時は独立する。
- 情報解禁日時は共通仕様のチェックボックスで設定を有効／無効にする。未設定は公開状態になった時点から公開する。

## 情報ブロック

- メイン画像
- 公演概要
- 公演紹介
- 公演日程
- 公演回
- 会場
- 出演者
- スタッフ
- チケット料金
- 公演クレジット

各ブロックは必要に応じて `release_at` を持つ。未設定は公開状態になった時点から公開する。管理画面は日本時間、DBはUTC。

## 公演日程

Productionに直接紐づく日付範囲。Performanceの親ではない。

## 公演回

Productionに直接紐づく日時レコード。開催日、開演時刻、終演予定時刻、任意のラベル、情報解禁日時を持つ。

情報解禁は**公演回ごとに独立**して設定する。同じProduction内でも公演回ごとに異なる日時で解禁できる。

ラベルは記号・ラベル名・表示順を持つ再利用定義。個数制限なし。表示は記号のみ／記号＋ラベル、凡例表示は任意。

## 会場

会場名は自由入力。Google Maps検索名またはURLを保持できる。会場情報と地図情報は別々に情報解禁できる。

## 出演者・スタッフ

1人1レコード。表示名、任意の役割、任意のメンバー参照、任意のAuthCoreユーザー参照、表示順を持つ。AuthCore参照は将来のチケット管理等で必要になった場合に利用する。

## チケット料金

料金項目はチケット種別、金額、予約画面表示フラグ、表示順。金額は0以上の整数円。料金ブロック全体に税込・税別・表示しないの三択と任意コメントを持つ。無料・未定を特別状態として管理しない。

## 公演クレジット

区分と項目の2階層。区分名・項目名は自由入力で重複チェックを行わない。項目は任意リンクを持つ。区分・項目とも表示順を持つ。情報解禁は区分単位。未解禁区分は区分名を含め公開しない。空区分は管理上保持できるが公開しない。解禁後の追加・編集・削除・並べ替えを制限しない。
