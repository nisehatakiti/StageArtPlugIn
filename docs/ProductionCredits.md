# 公演クレジット仕様

## 目的

Productionに紐づく協賛・協力・後援などのクレジット情報を管理する。区分名は固定せず、団体ごとに自由に構成できる。

## 区分

- 区分名は必須の自由入力。
- 同名区分の重複を許可する。システムによる重複チェックは行わない。
- 情報解禁日時は任意。未設定なら常時公開。
- 表示順を持ち、管理者が変更できる。
- 追加、編集、削除が可能。
- 削除時は、その区分に属する項目も削除する。
- 項目が存在する区分を削除する場合は、区分と項目をまとめて削除する旨を確認する。
- 項目が0件の空区分も管理上は登録できる。
- 公開側では、情報解禁済みであっても項目が0件の区分は表示しない。

## 項目

- 項目名は必須の自由入力。
- リンクは任意。指定時は名称をリンクとして表示する。
- 表示順を持ち、管理者が変更できる。
- 同名項目の重複を許可する。システムによる重複チェックは行わない。
- 追加、編集、削除が可能。
- 情報解禁後も追加、編集、削除、並べ替えが可能。

## 情報解禁

- 情報解禁は区分単位で設定する。
- 情報解禁前は区分自体を公開しない。
- 情報解禁前の区分について「近日公開」などのプレースホルダーは表示しない。
- 情報解禁日時を迎えた区分は、項目が1件以上あれば公開する。
- 情報解禁日時は「最初に公開可能になる日時」であり、解禁後の編集を制限しない。
- 公開判定はアクセス時に行い、cron等で公開状態を切り替えない。

## データモデル

### ProductionCreditSection

- `id`
- `production_id`
- `name`
- `release_at`（UTC、NULLは常時公開）
- `display_order`
- `created_at`
- `updated_at`

### ProductionCreditItem

- `id`
- `section_id`
- `name`
- `url`（任意）
- `display_order`
- `created_at`
- `updated_at`

## 公開表示

例：

```text
協賛
株式会社○○
株式会社△△

協力
○○劇場
○○文化会館

後援
○○市
```

情報解禁前の「協力」は、区分名を含めて表示しない。
